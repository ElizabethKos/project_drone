# Drone

## Описание

Drone — это консольное приложение, предназначенное для чтения, обработки и записи данных из различных файловых форматов. Приложение поддерживает работу с XML, JSON, а также может обрабатывать архивированные и зашифрованные файлы.

## Функциональность

- Чтение данных из входного файла.
- Обработка информации: нахождение арифметических операций и замена их на результаты.
- Запись обработанных данных в выходной файл.
- Поддержка различных форматов входных и выходных файлов.
- Возможность использования различных методов фильтрации.
